# BH_Merger_Ret
This is a repository for a project investiagating the retention rates of merging Binary Black Hole (BBH) systems. 

## Purpose
The purpose of this project is two fold:
1. Investigate a question that came to me when reading the literature
2. Research training and prep for the next PhD cycle

## Question
How sensitive is binary-black-hole remnant retention to progenitor spin alignment, spin magnitude, mass ratio, host escape velocity, and the recoil prescription?
